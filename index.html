Open source, in public

UniFi Fabric MCP Server

An open-source server that lets AI assistants manage UniFi networks through the official UniFi cloud API.

  • Tools across Network, Protect, Firewall, VPN, InnerSpace, Site Manager and more
  • Written in Python and published as a container image
  • Built for MSPs: one server can manage consoles across multiple API keys
  • High-risk writes need explicit confirmation on every call, and several write families are off by default
