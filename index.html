What we do

Four practices, one team. Each one feeds the others.

AI automation

We turn repetitive IT and back-office work into reliable automated workflows. AI agents do the work; people approve what matters.

  • AI agents connected to your systems through MCP (Model Context Protocol) servers
  • Workflow automation for operations, reporting and finance
  • Human review gates on every change that counts

Cloud and consulting

We plan, build and tidy up cloud environments so they are secure, documented and cheap to run. Then we hand over something your team can own.

  • Microsoft 365, identity and single sign-on
  • Infrastructure as code, CI/CD and container deployments
  • Architecture reviews and practical roadmaps

Enterprise networking and wireless

We design and run UniFi networks from the gateway to the access point, with segmentation and monitoring built in from day one.

  • Network design, VLAN segmentation and firewall policy
  • Wireless planning, deployment and tuning
  • Troubleshooting and remediation of existing networks

MSP services and MSP tooling

We deliver managed IT for businesses, and we build the tools that make managed IT faster to deliver at scale.

  • Ongoing managed IT support and monitoring
  • Multi-site and multi-tenant management tooling
  • Automation that lets a small team cover a large estate

Open source, in public

UniFi Fabric MCP Server

An open-source server that lets AI assistants manage UniFi networks through the official UniFi cloud API.

  • Tools across Network, Protect, Firewall, VPN, InnerSpace, Site Manager and more
  • Written in Python and published as a container image
  • Built for MSPs: one server can manage consoles across multiple API keys
  • Write actions are gated, and the riskiest ones ask for explicit confirmation

Why SWK Studios

We run what we sell

We operate our own production estate: virtualization hosts, single sign-on, a central log store and a segmented UniFi network. Every pattern we recommend has run on our own systems first.

AI with a review gate

Our agents do real work on real systems, and every significant change passes an independent review before it ships. Fast where it is safe, careful where it is not.

Built in the open

Our UniFi Fabric MCP Server is public and documented down to what was tested live and what was not. You can read our work before you hire us.

Why now

AI assistants can now operate real infrastructure through open standards like MCP. Most networks and most managed service providers are not ready for that. We are building the bridge, and we are already using it.
